# Branding

Approved logo (user approval, 2026-10-15): mint Q with a warm light bolt on a dark rounded tile. Preserve this design as the baseline. Editable source: assets/branding/querylight.svg; favicon: frontend/public/favicon.svg. Desktop exports: build/appicon.png and build/windows/icon.ico. These are deterministic vector/raster assets, not AI-generated artwork.

The executable icon also serves Windows shortcuts. Tray behavior is deferred; a monochrome adaptation can follow if a background workflow justifies it. Review 16/32 pixel rendering and Windows Explorer appearance before release. Naming/trademark availability is unchecked.

[Wails build guidance](https://wails.io/docs/guides/manual-builds/) describes icon inputs.
